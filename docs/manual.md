## Instalacion rapida desde repositorio
Itsuki es un lenguaje compilado en C y interpretado

Para comenzar la instalacion ejecuta el siguiente comando dentro de la carpeta itsuki
Recuerda tener instalado make
```bash
make
```

Esto te dara el ejecutable
